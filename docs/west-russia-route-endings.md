# 西俄罗斯路线速查

政治线只需完成前面的政治国策，即可选方向、更换政体、获得加成。经济和军事项目放在各自支线，不再卡住政治路线。

每个政治国策推进一次即可完成。不要求先占领指定省份、等到指定回合，或反复执行国家行动。国家行动是可选按钮，用不用都不影响政治终局。
